# 天天记账微信小程序

一个可以直接导入微信开发者工具运行的个人记账小程序 MVP。当前版本使用微信原生小程序框架实现，不依赖 npm，适合先验证产品流程和提交体验版。

## 已实现功能

- 首页：暗金图片背景、本日/本月/本年/账本总收支、预算进度、最近账目、收入排行。
- 记一笔：底部中间醒目入口、收入/支出切换、金额、分类、日期、备注。
- 明细：按月份和收支类型筛选、点击查看完整明细、显示提交时分秒、删除账目。
- 统计：月度收支、预算进度、收入/支出分类排行。
- 设置：月度预算、复制 JSON 备份、导入演示数据、清空账目。
- UI：金黄色主题、自定义底部导航，中间“记一笔”使用醒目的加号入口，页面使用年轻化美元钱包 logo。

## 本地运行

1. 安装并打开微信开发者工具。
2. 选择“导入项目”，目录选择本仓库根目录。
3. 首次开发可以使用测试号，或把 `project.config.json` 里的 `appid` 替换为你自己的小程序 AppID。
4. 点击“编译”，进入“设置 -> 导入演示数据”可以快速看到效果。

## 功能设计建议

### MVP 阶段

- 本地记账：支出、收入、分类、金额、日期、备注。
- 月度看板：本月支出、收入、结余、预算剩余。
- 明细管理：按月份筛选、删除记录。
- 统计分析：按分类聚合排行。
- 数据备份：复制 JSON，避免早期用户数据丢失。

### 下一阶段

- 微信登录和云同步：接入微信云开发数据库，按 `openid` 隔离用户数据。
- 自定义分类：允许新增、排序、隐藏分类。
- 周期账单：房租、会员费、工资等自动生成。
- 多账本：个人、家庭、生意、旅行账本。
- 导出文件：CSV/Excel 导出，适合长期留存。
- 消息提醒：预算超额、每日记账提醒。

## 框架选择

当前项目选择“微信原生小程序”是为了最短路径可运行、可预览、可上传。后续如果要做多端，建议二选一：

- Taro：适合熟悉 React/Vue、未来要扩展到 H5 或其他小程序端的团队。Taro 文档说明它遵循微信小程序规范，并可用 React/Vue 开发多端应用。
- uni-app：适合 Vue 技术栈和 HBuilderX 工作流。uni-app 文档说明可以发行到微信小程序，并生成微信小程序项目代码。

如果只做微信小程序，保持原生小程序 + Vant Weapp/TDesign Miniprogram UI 组件库会更轻；如果要多端和工程化协作，再迁移到 Taro 或 uni-app。

## 微信发布准备

1. 注册微信小程序账号并完成主体认证。
2. 在小程序后台拿到 AppID，替换 `project.config.json` 中的 `appid`。
3. 配置小程序名称、头像、类目、服务内容、隐私保护指引。
4. 如果接入服务器或云函数，配置服务器域名、业务域名、下载/上传域名；当前本地版不需要。
5. 准备测试账号、测试说明、核心页面截图，方便审核人员复现。
6. 确认隐私合规：如果收集用户信息、手机号、云端账单数据，需要在隐私保护指引里说明用途。

## 发布流程

1. 在微信开发者工具里导入项目并完成真机预览。
2. 替换正式 AppID，检查 `app.json` 页面路径、tabBar、权限声明。
3. 点击开发者工具右上角“上传”，填写版本号和项目备注。
4. 登录微信公众平台，进入小程序“版本管理/开发管理”，把开发版本提交审核。
5. 按页面提示补充功能页面、测试说明、隐私信息，提交微信审核。
6. 审核通过后，在后台点击发布；发布后用正式微信扫码回归核心流程。
